# Dentiva Pro

Offline-first Windows dental practice management for Bangladesh. Target stack: Tauri 2, React/TypeScript, Rust and SQLite. Currency: BDT. English UI with Bengali clinical text support.

**Engineering in progress — not a production release. No installer is currently available.**

Start with [build status](docs/BUILD_STATUS.md), [architecture](docs/ARCHITECTURE.md), [requirement traceability](docs/REQUIREMENTS_TRACEABILITY.md), and [release gates](docs/RELEASE_CHECKLIST.md). The specification is written before implementation; it is not a claim that the entire product is implemented.
